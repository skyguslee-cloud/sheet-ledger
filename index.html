사용법

1. 처음 시작하기

  1. 가족에게 받은 초대 링크를 누르면 구글 시트에 바로 연결돼요. 링크 대신 주소와 비밀번호를 받았다면 시작 화면에 넣으세요.
  2. 누구세요? 창에서 내 이름을 고르고 내 비밀번호(숫자 4~8자리)를 넣으세요. 처음이면 새로 만들어요. 이 기기에서 적는 내역은 그 이름으로 기록됩니다.
  3. 이름을 잘못 골랐다면 위쪽 내 이름을 눌러 바꾸면 됩니다.
  4. 시트 없이 이 휴대폰에서만 쓸 수도 있어요. 나중에 시트에 연결하면 그동안 적은 내역도 함께 올라가요.

내 내역은 어디에 저장되나요?

  • 먼저 이 휴대폰 안에 저장돼요. 인터넷이 안 돼도 입력할 수 있어요.
  • 인터넷이 되면 저장할 때마다, 그리고 1분마다 구글 시트와 주고받아요. 위쪽 작은 글자에 "동기화됨"이나 "보낼 것 N건"이 보여요.
  • 같은 내역을 두 사람이 고치면 나중에 고친 쪽이 남아요.
  • 시트에서 금액·메모를 직접 고쳐도 휴대폰에 반영돼요. 시트에서 줄을 지우지 말고 deleted 칸에 1을 넣으세요.

2. 돈 쓴 것 적기

  1. 아래 가운데 ＋ 버튼을 누릅니다.
  2. 금액을 넣고, 분류(식비, 카페 등)를 하나 누르고, 저장.
  3. 날짜는 오늘로 자동 입력됩니다. 지난 날짜는 날짜 칸을 눌러 바꾸세요.

같은 가게를 한 번 분류해 두면 다음부터 자동으로 그 분류가 선택됩니다.

3. 카드 문자로 한 번에 넣기

  1. 카드·은행 문자(카카오톡 알림)를 길게 눌러 복사합니다.
  2. ＋ → 카드·은행 문자로 넣기 → 붙여넣기 → 인식하기.
  3. 내용을 확인하고 선택 항목 추가. 여러 건을 한꺼번에 넣을 수 있어요.

4. 보고 고치기

  • 홈: 이번 달 분류별 합계. 큰 금액은 만원 단위(예: 160만원)로 짧게 보여요. 블록을 누르면 정확한 금액과 누가·어떻게 썼는지가 펼쳐지고, ✎로 고치고 🗑로 지웁니다.
  • 더보기 → 설정 → 사용자 이름에서 캐릭터를 눌러 나를 나타낼 이모지를 고를 수 있어요.
  • 잘못 지웠다면 아래에 잠깐 뜨는 되돌리기를 누르세요.
  • 내역: 전체 목록. 사람별, 수입/지출별로 골라 볼 수 있어요. 🔍 검색 칸에 사용처·분류·금액(예: 스타벅스, 45000)을 넣으면 모든 달에서 찾아 합계까지 보여줘요.
  • 가족이 저장한 내용은 구글 시트를 거쳐 1분 안팎으로 내 휴대폰에도 들어와요. 입력 중일 때는 다 쓰고 나서 화면이 바뀌어요.
  • 더보기 → 고정 수입·지출 · 카드 할부: 할부로 산 물건의 총 금액과 개월 수를 넣으면 매달 청구 금액이 자동 기록되고, 몇 회차인지와 남은 금액을 보여줘요. 미리 다 갚으면 중도 완납을 누르세요.
  • 더보기 → 엑셀·다른 가계부 가져오기: 다른 앱이나 은행·카드사의 엑셀·CSV 파일을 골라 열을 맞추면 지금 내역에 더해요. 이미 있는 내역은 건너뛰어요.
  • 더보기 → 설정 → 백업: 가계부 전체를 파일로 저장해요. 30일 넘게 백업하지 않으면 홈에 알림이 떠요.
  • 더보기 → 개인별 통계: 사람을 고르면 그 사람의 이번 달 수입·지출, 분류별 지출, 최근 6개월, 많이 쓴 곳, 가족 비교를 봅니다.
  • 위쪽 ‹ 11월 ›으로 다른 달을 봅니다.

5. 예산

  • 예산 탭에서 분류별 한 달 예산을 적습니다. 새 달이 되면 지난달 예산이 자동으로 이어집니다. 바꾸고 싶은 칸만 고치면 그 달에만 적용돼요.
  • 여행, 경조사·명절, 미용, 옷, 자동차보험·세금, 재산세, 가전·가구는 1년 예산으로 따로 관리합니다.
  • 가족 조건으로 추천: 예산 탭(또는 더보기 → 우리 가족 조건)에서 어른·아이 수와 학년, 사는 곳, 집, 차, 수입, 저축 목표를 넣으면 분류별 예산을 추천해 줘요. 칸을 고쳐서 저장하면 되고, 조건은 나중에 언제든 바꿀 수 있어요.
  • 막대가 회색 → 검정(80% 넘음) → 빗금(초과)으로 바뀝니다.
  • 월말 결산: 매달 25일부터 홈 화면에 알림이 뜹니다. 이번 달 쓴 돈을 확인하고, 최근 3개월 지출을 보고 추천한 금액으로 다음 달 예산을 정해 저장하세요. 예산 탭의 월말 결산 버튼으로 언제든 열 수 있어요.

6. 월급처럼 매달 들어오는 돈

  • 더보기 → 고정 수입·지출에 등록하면 매달 정한 날 자동으로 기록됩니다.
  • 금액이 바뀌면 금액 변경에서 "이번 달부터 / 다음 달부터"를 고르세요.

7. 휴대폰 홈 화면에 앱으로 두기 (꼭 해 주세요)

  • 안드로이드(크롬): 더보기 → 홈 화면에 앱으로 설치. 버튼이 없으면 크롬 메뉴(⋮) → 홈 화면에 추가.
  • 아이폰(사파리): 아래 공유 버튼(□↑) → 홈 화면에 추가. 그다음부터는 홈 화면 아이콘으로만여세요.
  • 아이폰은 사파리 저장 공간과 홈 화면 앱 저장 공간이 따로예요. 홈 화면 아이콘으로 처음 열면 초대 링크를 한 번 더 붙여넣어 주세요.
  • 아이폰 사파리는 홈 화면에 추가하지 않은 사이트의 저장 내용을 오래 안 쓰면 지울 수 있어요. 시트에 연결해 두면 지워져도 다시 받아올 수 있어요.

자주 묻는 질문

  • 가족이 적은 게 안 보여요 → 위쪽 "동기화" 글자를 누르면 바로 주고받아요. 상대방 휴대폰이 인터넷에 연결돼야 올라와요.
  • "보낼 것 N건"이 계속 남아 있어요 → 인터넷 연결을 확인하고 위쪽 글자를 눌러 보세요. 이 휴대폰에는 안전하게 저장돼 있어요.
  • 다른 사람 것도 적고 싶어요 → 더보기 → 설정 → 사용자 이름에서 "다른 사람 것도 입력"에 체크된 사람만 다른 사람 이름으로 적을 수 있어요.
  • 비밀번호를 잊어버렸어요 → "다른 사람 것도 입력"에 체크된 가족이 더보기 → 설정 → 사용자 이름에서 초기화를 누르면, 다음에 이름을 고를 때 새로 만들 수 있어요.
  • 새 휴대폰으로 바꿨어요 → 초대 링크로 다시 연결하면 시트에서 전부 받아와요. 시트 없이 썼다면 예전 휴대폰에서 백업 파일을 만들어 새 휴대폰에서 불러오세요.
